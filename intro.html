Tanya jawab

Pertanyaan umum

Ketuk pertanyaan untuk membaca jawabannya.

Apakah data saya aman?

Ya. Data kamu disimpan di browser di perangkatmu sendiri, bukan di server kami. Tidak ada akun yang harus dibuat, dan admin website ini tidak memiliki akses ke data pengguna mana pun.

Karena itu website ini bisa dipakai siapa saja tanpa pengumpulan data pribadi atau pelacakan aktivitas.

Perlu diingat: kalau data browser dihapus, aplikasi dibuka di perangkat lain, atau memakai browser berbeda, data tidak ikut berpindah. Gunakan Backup di Pengaturan untuk menyimpan salinan datamu secara berkala.

Apakah ada yang dikirim ke pihak lain?

Aplikasi tidak mengirim catatan, tugas, atau jadwalmu ke server kami.

Beberapa fitur memanggil layanan pihak ketiga hanya saat kamu memakainya: Spotify saat kamu menempel link Spotify, Google Books dan Open Library saat mencari buku, dan penerjemah saat menerjemahkan teks. Layanan itu punya kebijakan privasinya sendiri.

Apakah gratis?

Ya. Semua fitur yang ada sekarang bisa dipakai tanpa biaya dan tanpa langganan.

Pencarian buku, penerjemah, dan pemutar Spotify butuh internet. Fitur lainnya tetap bisa dipakai setelah halaman dibuka.

Bisa dipakai di HP?

Bisa. Tampilannya menyesuaikan layar HP dan laptop, dengan menu yang bisa dibuka dari tombol garis tiga.

Untuk hasil terbaik di HP, buka lewat Chrome atau Safari, lalu tambahkan ke layar utama lewat menu browser.

Kenapa alarm tidak berbunyi saat HP terkunci?

Alarm dan timer hanya berbunyi selama aplikasi terbuka di layar. Ini batasan aplikasi berbasis web, karena browser HP menghentikan halaman yang tidak aktif.

Supaya alarm tetap berbunyi, biarkan layar menyala atau buka aplikasi sebelum jam alarm tiba.

Bagaimana memindahkan data ke HP lain?

Di perangkat lama, buka Pengaturan lalu pilih Backup untuk mengekspor semua data, termasuk file dan musik yang diunggah.

Di perangkat baru, buka aplikasi lalu pilih Impor di Pengaturan dan pilih berkas backup tadi. Data di perangkat baru akan diganti, jadi pastikan berkas yang dipilih benar.
